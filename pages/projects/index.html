1Recon

Modern Reconnaissance Automation Framework

Bash Recon Framework Active Dev
GitHub

1Recon is a Bash-based reconnaissance automation framework designed to streamline the initial information-gathering phase of penetration testing and bug bounty assessments. It combines multiple reconnaissance and enumeration tools into a single workflow — helping security researchers discover subdomains, validate DNS records, identify open ports and services, detect web technologies, enumerate directories, crawl web applications, and organize reconnaissance results.

Features

  • Subdomain enumeration (Subfinder & Assetfinder)
  • Automatic result deduplication
  • DNS validation using dnsx
  • Port scanning with Nmap
  • HTTP probing via httpx
  • Technology detection with Wappalyzer
  • Directory enumeration with Gobuster
  • Web crawling using Katana
  • WHOIS information gathering
  • Organized per-target output
  • Colored terminal output & status messages
  • Automatic dependency detection

Requirements

Bash Subfinder Assetfinder dnsx Nmap httpx WHOIS Wappalyzer Gobuster Katana

Reconnaissance Workflow

Installation & Usage

bash
git clone https://github.com/mr-farhankhan/1Recon.git cd 1Recon chmod +x 1Recon.sh ./1Recon.sh -d example.com
